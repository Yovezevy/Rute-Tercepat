# Rute-Tercepat

## Fungsi
Aplikasi web untuk menghitung dan memvisualisasikan rute pengiriman kurir terpendek serta urutan pengantaran paket ke sejumlah lokasi tujuan.

## Bahasa dan Stack
HTML5, CSS3, JavaScript

## Cara Build dan Menjalankan
Buka berkas index.html langsung pada peramban web, atau jalankan melalui server lokal statis seperti Live Server.

## Fitur Utama
- Perhitungan jalur terpendek antar titik lokasi menggunakan algoritma Dijkstra.
- Penentuan urutan rute multi tujuan menggunakan metode Greedy TSP dan Brute Force TSP.
- Visualisasi graf interaktif yang menampilkan simpul lokasi dan jalur pengiriman.
- Penambahan dan penghapusan titik tujuan pengiriman oleh pengguna.
- Pengaturan tema antarmuka dan warna aksen tampilan.
